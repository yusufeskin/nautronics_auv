# AUV Navigation (auv_navigation)

The `auv_navigation` package provides path planning and navigation capabilities for the AUV.

## Overview

This package is responsible for determining the optimal path for the AUV to traverse its environment, avoiding obstacles and reaching target waypoints.

## Structure

- **`src/`**: Source code for navigation algorithms.
- **`model/`**: Models used for navigation (e.g., neural networks or maps).
- **`dataset/`**: Data used for training or validation.
